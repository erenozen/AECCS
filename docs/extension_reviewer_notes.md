# AECCS Extension Reviewer Notes

## Reviewer Summary

AECCS Cookie Compliance Checker is a passive, on-demand browser extension that analyzes the currently active webpage for GDPR cookie-consent compliance. It does not auto-click banners, block requests, crawl in the background, or send browsing data to any remote service.

## Why These Permissions Are Needed

- `cookies`: read cookies already set on the active page so they can be classified and counted
- `activeTab`: determine which page the user explicitly asked the extension to analyze
- `scripting`: inject the consent scanner into the active tab only when the user opens the popup
- `<all_urls>` host permission: required by the cookies API to read cookies for the current page URL; not used for background fetching or remote communication

## Generated Static Assets

Three generated files may look unusual because they are large, but each is a static local artifact bundled into the extension package:

- `extension/lib/shared-config.js`
  - generated by `scripts/build_extension_shared_config.py`
  - contains Python-owned shared scanner/classifier constants exported into a local extension payload
- `extension/lib/study-snapshot.js`
  - generated by `scripts/build_extension_study_snapshot.py`
  - contains frozen AECCS study metadata, PET results, and CMP results from `data/real_combined/processed/`
- `extension/lib/tracker-index.js`
  - generated by `scripts/build_extension_tracker_index.py`
  - contains a compact precompiled tracker-domain index derived from local EasyPrivacy and EasyList inputs

These files are not downloaded at runtime, do not execute remote code, and do not change extension permissions.

## Runtime Privacy Posture

- no network requests
- no analytics or telemetry
- no account system
- no cloud sync or server storage
- no remote configuration or remote code loading
- all analysis stays local to the user’s browser session

## Packaging Notes

- Upload package: archive of the `extension/` directory only, with `manifest.json` at the root of the ZIP
- Reviewer/source package: include `extension/`, `scripts/build_extension_shared_config.py`, `scripts/build_extension_study_snapshot.py`, `scripts/build_extension_tracker_index.py`, `docs/privacy-policy.html`, and release docs
- Firefox submission package adds `background.scripts` only as a Firefox compatibility fallback; Chrome continues to use the MV3 `background.service_worker` manifest shape
- `browser_specific_settings.gecko.data_collection_permissions.required = ["none"]` explicitly declares that the extension does not collect or transmit data off-device
- Store listing and privacy policy are aligned with the actual runtime behavior in the shipped extension
- Public privacy policy URL for store submission: `https://erenozen.github.io/AECCS/privacy-policy.html`
